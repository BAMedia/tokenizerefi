# TokenizeRefi

Homeowner waitlist page for https://tokenizerefi.com/, served by GitHub Pages from `main` (root). A Bay Area Media project (https://bamedia.agency/). Sister projects: ProtectReal, NFTitleMint.

Static HTML/CSS. The waitlist form composes a `mailto:` to john@bamedia.agency (subject "tokenizerefi waitlist"); no third-party form service. To repoint to a form backend later, set the form's `action` to the endpoint and remove its `data-mailto` attribute.
